# 算术练习
Blender 5.2 插件，行测资料分析速算刷题工具。

## ✨功能
- 混合模式：连续刷题，结束输出本轮完整统计报告（总用时、总题数、正确率、每题明细、题型标记）
- 单题型模式：选定专项题型练习，每题即时查看标准答案
- 内置速算技巧、大数硬算、小数百分数运算，贴合行测资料分析计算训练

## 🧩环境要求
Blender 5.2 及更高版本
## 📖使用说明
### 混合模式
点击 Ready 开始刷题；点击「下一题」后台记录数据；随时点【提交】结束本轮，生成本轮完整统计明细。
> 混合模式下不显示速算思路。

### 单项类型
选择对应专项题型，支持查看速算思路，一题一判。

> 注意：空提交直接判错，答案支持整数、小数、负数输入。
